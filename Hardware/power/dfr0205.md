# DFRobot DFR0205 DC-DC Power Distribution Module

![DFR0205](https://image.dfrobot.com/image/data/DFR0205/DFR0205-3.jpg)

**Role in MyBot:** Central power distribution. Takes 12V from the main battery, provides a regulated 5V rail for the Raspberry Pi, and passes 12V directly through to the motor driver (TB6612 VM input).

---

## Specs

| Parameter | Value |
|---|---|
| IC | GS2678 (synchronous buck converter) |
| Input voltage | 3.6V – 25V |
| Output voltage | 3.3V – 25V (adjustable) |
| Constant output current | 5A |
| Max output power | **25W** |
| Switching frequency | 350 kHz |
| Output interfaces | 3 regulated + 1 passthrough (raw input voltage) |
| Control | ON/OFF button |
| Dimensions | 46 × 50 × 20 mm |

> ⚠️ Input voltage must always be **higher** than the set output voltage for the buck converter to regulate correctly.

---

## MyBot power allocation

| DFR0205 output | Set voltage | Connected to | Peak draw |
|---|---|---|---|
| Regulated output 1 | **5V** | Raspberry Pi 4 (USB-C) | 3A |
| Regulated output 2 | — | Spare | — |
| Regulated output 3 | — | Spare | — |
| Passthrough (raw input) | **12V** | TB6612 VM (motor power) | ~4A (2 motors) |

---

## System power chain

```
12V Battery
    │
    ├── DFR0205 regulated 5V ──────────→ Raspberry Pi 4 (USB-C, 3A min)
    │       │
    │       └── Pi USB ports
    │               ├── Arduino Nano (power + serial data)
    │               ├── RPLidar A1   (~400mA)
    │               ├── RealSense D435 (~900mA, USB 3.0)
    │               └── ESP32-S3     (~250mA peak, when in use)
    │
    └── DFR0205 12V passthrough ───────→ TB6612 VM (motor supply)
                                                │
                                         ┌──────┴──────┐
                                      Left motor    Right motor
```

## Power budget check

| Consumer | Rail | Current |
|---|---|---|
| Raspberry Pi 4 (idle + WiFi) | 5V | ~1.5A |
| RPLidar A1 | 5V via Pi USB | ~0.4A |
| RealSense D435 | 5V via Pi USB 3.0 | ~0.9A |
| Arduino Nano | 5V via Pi USB | ~0.05A |
| **Total 5V regulated** | | **~2.85A** |
| **DFR0205 5V limit** | | **5A** |
| Left motor (stall) | 12V passthrough | ~1.5A |
| Right motor (stall) | 12V passthrough | ~1.5A |
| **Total 12V passthrough** | | **~3A stall** |

> Margin exists on the 5V rail. ESP32-S3 (~250mA) can be added without exceeding 5A limit. The 12V passthrough is limited only by the battery and wiring gauge.

---

## Wiring

```
Battery (+) → DFR0205 IN+
Battery (−) → DFR0205 IN−

DFR0205 5V OUT+ → Pi USB-C (+)
DFR0205 5V OUT− → Pi USB-C (−) / GND

DFR0205 Passthrough OUT+ → TB6612 VM
DFR0205 Passthrough OUT− → TB6612 GND (common ground)
```

**Ground must be common** across: battery, DFR0205, Pi, Arduino/ESP32, TB6612, encoders.

---

## Adjusting output voltage

The DFR0205 output voltage is set via a trimmer potentiometer on the board. Use a small flathead screwdriver:
- Clockwise → increases voltage
- Counter-clockwise → decreases voltage
- Measure with a multimeter at the output terminals before connecting load
